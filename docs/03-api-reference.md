# REST API Reference

[← Database Schema](02-database.md) · [Payment Gateways →](04-payment-gateways.md)

---

## Base URL

```
/wp-json/wp-booking-system/v1/
```

All requests require the `X-WP-Nonce` header with a nonce generated by `wp_create_nonce('wp_rest')`. The nonce is printed into the page via `wp_localize_script`.

Authentication uses WordPress cookies (the default REST API authentication). For headless or mobile clients, use an Application Password.

---

## Authentication Levels

| Level | Check | Endpoints |
|---|---|---|
| **Public** | None | `GET /services`, `GET /services/{id}`, `GET /availability`, `GET /available-dates` |
| **Customer** | `is_user_logged_in()` | Booking creation, payment initiation, `GET /my-bookings` |
| **Admin** | `manage_options` capability | All booking management, service CRUD, payments, refunds |
| **Ownership** | Customer ID matches current user OR admin | `GET /bookings/{id}`, `POST /bookings/{id}/cancel` |

## Services

### `GET /services`

Returns all active services. No authentication required.

**Response `200`**
```json
[
  {
    "id": 1,
    "name": "Deep Tissue Massage",
    "description": "60-minute therapeutic massage targeting muscle tension.",
    "duration": 60,
    "capacity": 1,
    "price": "75.00",
    "category": "Massage",
    "image_id": null,
    "is_active": "1",
    "sort_order": "0"
  }
]
```

---

### `POST /services`

Create a new service. Requires `manage_options`.

**Request body**
```json
{
  "name": "Swedish Massage",
  "description": "Relaxing full-body massage.",
  "duration": 60,
  "capacity": 1,
  "price": 65.00,
  "category": "Massage",
  "is_active": 1,
  "sort_order": 0
}
```

**Response `201`** — Returns the created service object.

---

### `GET /services/{id}`

Retrieve a single service by ID. No authentication required.

**Response `200`** — Service object.  
**Response `404`** — `{ "code": "not_found", "message": "Service not found." }`

---

### `PUT /services/{id}`

Update a service. Requires `manage_options`. Send only the fields to update.

---

### `DELETE /services/{id}`

Delete a service. Requires `manage_options`. Returns `409 Conflict` if the service has active bookings (non-cancelled, non-completed).

**Response `409`**
```json
{
  "code": "delete_failed",
  "message": "Cannot delete service with active bookings."
}
```

## Availability

### `GET /availability`

Returns available time slots for a service on a specific date.

**Query parameters**

| Param | Type | Required | Description |
|---|---|---|---|
| `service_id` | integer | Yes | ID of the service |
| `date` | string | Yes | Date in `YYYY-MM-DD` format |

**Response `200`**
```json
{
  "slots": ["09:00", "09:30", "10:00", "10:30", "14:00", "14:30"]
}
```

Returns an empty `slots` array when no slots are available (day closed, fully booked, outside advance booking window).

---

### `GET /available-dates`

Returns all bookable dates in a given month. Used to highlight available days on the calendar.

**Query parameters**

| Param | Type | Required | Description |
|---|---|---|---|
| `service_id` | integer | Yes | ID of the service |
| `month` | integer | Yes | Month number (1–12) |
| `year` | integer | Yes | Four-digit year |

**Response `200`**
```json
{
  "dates": ["2025-08-04", "2025-08-05", "2025-08-06", "2025-08-11"]
}
```

## Bookings

### `GET /bookings`

List all bookings. Requires `manage_options`.

**Query parameters**

| Param | Type | Description |
|---|---|---|
| `status` | string | Filter by `booking_status` |
| `date_from` | string | Start date (`YYYY-MM-DD`) |
| `date_to` | string | End date (`YYYY-MM-DD`) |
| `search` | string | Full-text search on ref, customer name, email |
| `per_page` | integer | Results per page (default: 20) |
| `offset` | integer | Pagination offset |

**Response `200`**

Returns an array of booking objects. The total count is available in the `X-WP-Total` response header.

```json
[
  {
    "id": 42,
    "booking_ref": "WPBS-A3F2X9",
    "customer_id": "7",
    "service_id": "1",
    "service_name": "Deep Tissue Massage",
    "customer_name": "Jane Smith",
    "customer_email": "jane@example.com",
    "booking_date": "2025-08-15",
    "booking_time": "10:00:00",
    "end_time": "11:00:00",
    "duration": "60",
    "amount": "75.00",
    "payment_method": "stripe",
    "payment_status": "paid",
    "booking_status": "confirmed",
    "notes": "",
    "admin_notes": null,
    "created_at": "2025-08-01 14:22:11"
  }
]
```

---

### `POST /bookings`

Create a booking. Requires login. The `customer_id` is set server-side to the authenticated user's ID and cannot be overridden.

**Request body**
```json
{
  "service_id": 1,
  "booking_date": "2025-08-15",
  "booking_time": "10:00",
  "payment_method": "stripe",
  "notes": "Please use low-fragrance oils."
}
```

**Response `201`** — Returns the created booking object.  
**Response `422`** — `{ "code": "booking_failed", "message": "This time slot is no longer available." }`

---

### `GET /bookings/{id}`

Retrieve a single booking. Accessible by the booking's owner or an admin.

---

### `PUT /bookings/{id}`

Update booking status or admin notes. Requires `manage_options`.

**Request body**
```json
{
  "booking_status": "confirmed",
  "admin_notes": "Called to confirm — all good."
}
```

---

### `DELETE /bookings/{id}`

Permanently delete a booking record. Requires `manage_options`. This is a hard delete; consider setting status to `cancelled` instead for audit purposes.

---

### `POST /bookings/{id}/cancel`

Cancel a booking. Accessible by the booking's owner (subject to cancellation window) or an admin (no window restriction).

**Request body**
```json
{
  "reason": "Schedule conflict"
}
```

**Response `200`** — Updated booking object.  
**Response `403`** — Cancellation window has passed.

## Payments

### `POST /payments/paypal/create-order`

Initiate a PayPal payment for an existing booking. Returns the approval URL to redirect the customer.

**Request body**
```json
{
  "booking_id": 42
}
```

**Response `200`**
```json
{
  "success": true,
  "order_id": "4WB12345X67890123",
  "approval_url": "https://www.sandbox.paypal.com/checkoutnow?token=..."
}
```

---

### `POST /payments/paypal/capture`

Capture an approved PayPal order. Call this after the customer returns from the PayPal redirect.

**Request body**
```json
{
  "order_id": "4WB12345X67890123",
  "booking_id": 42
}
```

**Response `200`**
```json
{
  "success": true,
  "capture_id": "7GH98765Y12345678"
}
```

---

### `POST /payments/stripe/create-intent`

Create a Stripe PaymentIntent. Returns the `client_secret` needed by Stripe.js on the frontend.

**Request body**
```json
{
  "booking_id": 42
}
```

**Response `200`**
```json
{
  "success": true,
  "payment_intent_id": "pi_3PqRsT...",
  "client_secret": "pi_3PqRsT..._secret_...",
  "publishable_key": "pk_test_..."
}
```

---

### `POST /payments/stripe/confirm`

Confirm that a Stripe PaymentIntent succeeded (called after `stripe.confirmCardPayment` returns `succeeded`).

**Request body**
```json
{
  "payment_intent_id": "pi_3PqRsT...",
  "booking_id": 42
}
```

**Response `200`** — `{ "success": true }`

---

### `POST /payments/{id}/refund`

Process a full or partial refund. Requires `manage_options`.

**Request body**
```json
{
  "amount": 37.50
}
```

**Response `200`** — `{ "success": true, "refund_id": "re_3Pq..." }`  
**Response `422`** — Refund amount exceeds balance, or payment not in `completed` state.

---

## Customer Endpoints

### `GET /my-bookings`

Returns the authenticated customer's own bookings. No admin privileges required.

**Query parameters** — same as `GET /bookings` except `search` and no cross-customer results.

## Error Format

All errors follow the WP REST API convention:

```json
{
  "code": "machine_readable_slug",
  "message": "Human-readable explanation.",
  "data": {
    "status": 422
  }
}
```

| HTTP Status | Meaning |
|---|---|
| `400` | Malformed request or unknown action |
| `401` | Not authenticated |
| `403` | Authenticated but not authorized |
| `404` | Resource not found |
| `409` | Conflict (e.g., delete with active bookings) |
| `422` | Business rule violation (slot taken, refund exceeds balance) |
| `500` | Unexpected server error |
